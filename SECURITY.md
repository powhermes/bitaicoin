# Security Policy

BitAIcoin is a fork of Bitcoin Core v31.1. Do **not** report BitAIcoin issues to the
Bitcoin Core security team; they do not maintain this software.

## Supported Versions

Only the latest release listed at https://bitaicoin.com/downloads/ is supported.

## Reporting a Vulnerability

Email **support@bitaicoin.com** with the details. Please do not open a public issue for
anything that could put funds, nodes or the network at risk until it has been fixed.

You can encrypt to, and verify releases with, the BitAIcoin release key:

`9F11 E836 EB4B 7F46 4ADB B1E7 AC11 CA67 4828 CAE1`
(published at https://downloads.bitaicoin.com/bitaicoin-release-signing-key.asc)

If the issue also affects upstream Bitcoin Core, say so in your report so it can be
passed on responsibly: https://bitcoincore.org/en/contact/
